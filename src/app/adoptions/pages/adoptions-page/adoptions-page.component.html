Adopciones Gatarsis

Adoptar también es empezar una nueva historia

Queremos encontrar el hogar indicado para cada gatito y acompañar una adopción responsable, segura y para toda la vida.

Completar el cuestionario no implica una adopción automática ni genera obligación alguna. Nos ayuda a conocer mejor cada hogar y encontrar la combinación más adecuada para el gatito y la familia.

Una condición esencial

Adopción únicamente para hogares de interior

No se entregan gatitos para vida en la calle ni con libre acceso al exterior.

Un hogar protegido también es una forma de amor.
